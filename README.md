# Jenista Chit App

A Chit Fund Management System featuring a TypeScript/Node.js backend and a React/TypeScript/Vite frontend.

## Project Structure

- `frontend/`: React + TypeScript + Vite frontend application.
- `backend/`: Node.js + Express + TypeScript + MongoDB backend application.

## Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB

### Backend Setup
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
